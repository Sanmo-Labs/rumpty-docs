# Settings

Settings live in two places: account-level settings on your profile, and per-workspace settings.

## Profile

Open **Manage Profile → My profile** in the top-right navbar. The profile page has three tabs:

| Tab | What it covers |
|-----|----------------|
| [Account](./account) | Profile info, account policies, billing and tax details, billing cycle, free usage, change password |
| [Workspaces](./workspaces) | View and delete your workspaces |
| [Personal API keys](./api-keys) | Create tokens for CLI tools and automation |

## Workspace settings

Open **Settings** in the sidebar. Changes here affect only the selected workspace. It has four tabs:

| Tab | What it covers |
|-----|----------------|
| General | Workspace details and the permissions of your role |
| [SSH keys](./ssh-keys) | Add and manage SSH keys injected into new VMs |
| [GitHub](./integrations) | Connect GitHub for deployments |
| Team | Members, roles, and invitations |
