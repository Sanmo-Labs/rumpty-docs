# Settings

Access your profile and account settings from **Manage Profile** in the top-right navbar. Settings are organised into five tabs:

| Tab | What it covers |
|-----|----------------|
| [Account](./account) | Profile info, account policies, billing cycle, free usage, change password |
| [Workspaces](./workspaces) | View and delete your workspaces |
| [Integrations](./integrations) | Connect GitHub for deployments |
| [SSH Keys](./ssh-keys) | Add and manage SSH keys injected into new VMs |
| [API Keys](./api-keys) | Create tokens for CLI tools and automation |
