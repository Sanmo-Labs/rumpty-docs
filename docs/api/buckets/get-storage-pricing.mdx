<Endpoint method={"GET"} path={"/v1/storage/pricing"} />

Returns the current storage price sheet: the monthly price per GiB and the free allowance
for block volumes, snapshots, object storage (buckets) and build artifact storage.

This endpoint is public and needs no API key or workspace.

## Authentication

This endpoint is public. No API key is needed.
