<Endpoint method={"POST"} path={"/v1/asset-objects/{uid}/read-url"} />

Returns a URL to download a `ready` object. Send no request body.

- In a **private** bucket the URL is presigned. It works without authentication until
  `expires_at` (10 minutes by default, never more than 7 days) and `is_signed` is `true`.
- In a **public** bucket the object's permanent public URL is returned, `is_signed` is
  `false` and `expires_at` is omitted.

Requires read access to the workspace (any role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The object's `uid` (the `object_id` returned by [Create an upload](/api/buckets/create-an-upload)).

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

A URL to read the object.

URL to download the object.

<Param name={"expires_at"} type={"string (date-time)"}>

When the URL stops working. Omitted for public URLs, which do not expire.

</Param>

<Param name={"is_signed"} type={"boolean"} required>

`true` for a presigned URL from a private bucket, `false` for a public URL.

</Param>

## Errors

| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | The object (or its bucket) does not exist in this workspace. |
| `409` | The object is not `ready`, for example its upload has not been completed. |
