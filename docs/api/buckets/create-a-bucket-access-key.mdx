<Endpoint method={"POST"} path={"/v1/asset-buckets/{uid}/access-keys"} />

Creates an S3 access key scoped to this bucket, for use with any S3-compatible client (AWS
CLI, SDKs, rclone and so on). Point the client at `endpoint` and `region`, and use `bucket`
as the bucket name.

The `secret_access_key` appears **only in this response**. Store it securely, because it
cannot be retrieved again.

The key starts in `provisioning` while it is granted on storage, and becomes `active` when
the operation finishes. Poll [Get an operation](/api/operations/get-an-operation) with
`operation_id` before using the key. If provisioning fails the key's status is `failed`.

The bucket must be `ready`. Requires the `secrets manage` permission (owner, admin or
developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
