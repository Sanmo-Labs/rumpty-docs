<Endpoint method={"GET"} path={"/v1/asset-buckets/{uid}/access-keys"} />

Returns the bucket's S3 access keys, newest first. Revoked keys are not included. Secret
access keys are never returned, only the `access_key_id`.

Requires the `secrets read` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The bucket's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
