S3-compatible object storage buckets for files such as images, documents and video. A bucket
is either `public` (objects are served from a public URL) or `private` (objects are read
through short-lived signed URLs).

Creating and deleting a bucket is asynchronous. The request returns `202 Accepted` with an
`operation_id`. Poll [Get an operation](/api/operations/get-an-operation) to follow it.

To upload a file, use three steps:

1. [Create an upload](/api/buckets/create-an-upload) to get a presigned `upload_url`.
2. `PUT` the file's bytes to that URL with the returned headers.
3. [Complete an upload](/api/buckets/complete-an-upload) to mark the object ready.

For direct S3 access from your own tools, create a
[bucket access key](/api/buckets/create-a-bucket-access-key).

The first 10 GiB of file storage per account is free. Uploads that would go over the free
allowance are rejected while billing for storage is not enabled.
