<Endpoint method={"POST"} path={"/v1/asset-buckets"} />

Queues a new bucket and returns `202 Accepted` with the `operation_id` of the create
operation. The bucket starts in `provisioning` and moves to `ready` (or `failed`) when the
operation finishes. Poll [Get an operation](/api/operations/get-an-operation) or
[List buckets](/api/buckets/list-buckets) to see when it is `ready`. Uploads, access keys
and CORS changes are only accepted once the bucket is `ready`.

Things to know:

- Bucket names must be unique in the workspace. Uniqueness is checked on the slug of the
  name, so `Marketing Assets` and `marketing-assets` clash.
- `visibility` defaults to `public`. It cannot be changed after creation.
- The underlying S3 bucket name (`s3_bucket_name`) is generated for you from the workspace
  slug and the bucket's ID.
- Send `X-Idempotency` to make retries safe. Repeating a create with the same key returns
  the original operation with `200 OK` and `is_replay: true`, and no second bucket is
  created. The key is checked first, before the past-due check and validation. Reusing it
  for a different action returns `409` with `action: idempotency_key_reused`.
- Past-due or suspended accounts cannot create buckets (`402`, `action: past_due`).

Requires the `resource write` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

<Param name={"X-Idempotency"} type={"string"}>

Optional key that makes retries safe. Repeating a request with a key already used for
the same action returns the original operation with `200 OK` and `is_replay: true`
instead of queuing it again. Reusing it for a different action or bucket returns `409`
with `action: idempotency_key_reused`.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `400` | Validation failed. Possible messages: `invalid request` (malformed JSON or missing `name`), `name is required` (blank after trimming), `visibility must be public or private`. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `402` | The account is past due, so new paid resources cannot be created. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `409` | A bucket with the same name (slug) already exists in this workspace, or the `X-Idempotency` key was already used for a different action (`action: idempotency_key_reused`). |

Errors use the [standard error format](/api#errors).
