<Endpoint method={"GET"} path={"/v1/asset-buckets/usage"} />

Returns how many bytes the workspace's bucket objects use, compared with the account's free
file storage allowance, plus the maximum size of a single upload.

Only objects whose upload has been completed (status `ready`) are counted. The free
allowance is shared across all your workspaces. See
[Get account storage usage](/api/buckets/get-account-storage-usage) for the account-wide
total.

Requires read access to the workspace (any role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

<ParamChildren open label={"attributes"}>

<Param name={"used_bytes"} type={"integer"} required>

Total size of the workspace's `ready` bucket objects, in bytes.

</Param>

<Param name={"free_bytes"} type={"integer"} required>

Your account's free file storage allowance, in bytes.

</Param>

<Param name={"billable_bytes"} type={"integer"} required>

Bytes above the free allowance (`used_bytes` minus `free_bytes`, never below zero).

</Param>

<Param name={"max_upload_bytes"} type={"integer"} required>

Maximum size of a single upload, in bytes.

</Param>

<Param name={"usage_percentage"} type={"integer"} required>

`used_bytes` as a whole-number percentage of `free_bytes`, rounded down. Can exceed 100.

</Param>

</ParamChildren>
