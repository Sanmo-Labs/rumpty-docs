<Endpoint method={"GET"} path={"/v1/storage/usage"} />

Returns how much storage your account uses across **all** your workspaces, split into file
storage (bucket objects) and build artifacts (deployment builds), compared with the free
allowance.

This endpoint is account-level, so it does not take an `X-Workspace-Slug` header. For a
single workspace's bucket usage, use
[Get workspace bucket usage](/api/buckets/get-workspace-bucket-usage).

Only objects whose upload has been completed (status `ready`) count towards usage.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.
