<Endpoint method={"GET"} path={"/v1/api-keys"} />

Returns your active API keys. Secret tokens are never returned, only the `prefix` that identifies each key.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Response

<ResponseBlock status={"200"}>

Your API keys.

</ResponseBlock>

<Param name={"uid"} type={"string"} required>

Unique identifier of the key.

</Param>

<Param name={"name"} type={"string"} required>

Label you gave the key.

<Param name={"prefix"} type={"string"} required>

First 8 characters of the token's identifier, used to recognise the key.

</Param>

<Param name={"scopes"} type={"array of strings"} required enumValues={["cli","mcp"]}>

</Param>

<Param name={"never_expires"} type={"boolean"}>

Present and `true` when the key has no expiry.

</Param>

<Param name={"expires_at"} type={"string (date-time)"}>

When the key expires (RFC 3339, UTC). Omitted for keys that never expire.

</Param>

<Param name={"created_at"} type={"string (date-time)"} required>

When the key was created.

</Param>

<Param name={"last_used_at"} type={"string (date-time)"}>

When the key last authenticated a request. Omitted if it has never been used.

</Param>
