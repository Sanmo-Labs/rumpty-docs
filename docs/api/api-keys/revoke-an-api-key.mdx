<Endpoint method={"DELETE"} path={"/v1/api-keys/{uid}"} />

Revokes the key immediately. Requests using it are rejected with `401` from then on.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The key's `uid`.

</Param>

## Response

<ResponseBlock status={"200"}>

The key was revoked.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `404` | The resource does not exist or you cannot access it. |

Errors use the [standard error format](/api#errors).
