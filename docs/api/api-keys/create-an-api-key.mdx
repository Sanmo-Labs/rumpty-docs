<Endpoint method={"POST"} path={"/v1/api-keys"} />

Creates a personal API key. The full `token` appears **only in this response**. Store it
securely, because it cannot be retrieved again.

Keys expire after 365 days by default. Set `expires_in_days` to choose a lifetime (capped at
730 days), or set `never_expires` to `true`. Do not send both.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Request body

<Param name={"name"} type={"string"} required>

Label for the key. Must be unique among your keys.

</Param>

<Param name={"expires_in_days"} type={"integer"} constraints={"min 1 · max 730"}>

Days until the key expires. Defaults to `365`. Values above `730` are capped at `730`.

</Param>

<Param name={"never_expires"} type={"boolean"} defaultValue={"false"}>

Create a key that never expires. Cannot be combined with `expires_in_days`.

</Param>

<Param name={"scope"} type={"string"} defaultValue={"cli"} enumValues={["cli","mcp"]}>

What the key is for. `cli` covers the CLI and REST API. `mcp` is for the Rumpty MCP server.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `400` | Validation failed: `name` is missing or already used, `scope` is not `cli` or `mcp`, or both `never_expires` and `expires_in_days` were sent. |
| `401` | The API key is missing, invalid, expired or revoked. |

Errors use the [standard error format](/api#errors).
