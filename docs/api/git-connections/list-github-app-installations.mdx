<Endpoint method={"GET"} path={"/v1/git-connections/github-app/installations"} />

Returns the GitHub accounts and organizations connected to this workspace, most recently
connected first.

Each connection lists `dependent_deployments`: the workspace's deployments that build from
that GitHub account's repositories and would stop building if the connection were removed.

Requires the `secrets read` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

<Param name={"connected_by_former_member"} type={"boolean"}>

Present and `true` when the member who connected it has since left the workspace. The connection keeps working until it is disconnected.
