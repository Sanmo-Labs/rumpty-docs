Connect GitHub accounts and organizations to a workspace through the RumptyCloud GitHub App,
so deployments can build from your repositories. Once connected, list the repositories and
branches the app can see and detect how a repository should be built.

A workspace can have several GitHub connections, one per GitHub account or organization.
Connecting a new account happens in the browser on GitHub: get an install URL with
[Get the GitHub App install URL](/api/git-connections/get-the-github-app-install-url) and open
it. If you already connected the account in another workspace, you can
[link that connection](/api/git-connections/link-a-github-app-installation) instead.
