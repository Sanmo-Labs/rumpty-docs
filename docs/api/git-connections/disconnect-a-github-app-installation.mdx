<Endpoint method={"DELETE"} path={"/v1/git-connections/github-app/installations/{uid}"} />

Removes a GitHub connection from this workspace. Deployments that build from that GitHub
account's repositories (see `dependent_deployments` in
[List GitHub App installations](/api/git-connections/list-github-app-installations)) can no
longer build from git.

**If no other workspace uses the same GitHub installation, the RumptyCloud GitHub App is
also uninstalled from the GitHub account or organization.** When other workspaces still
use it, only this workspace's connection is removed.

Requires the `workspace manage` permission (owner or admin role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The connection's `uid` from [List GitHub App installations](/api/git-connections/list-github-app-installations).

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The connection was removed.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | The connection does not exist in this workspace. |
| `500` | Uninstalling the app on GitHub or removing the connection failed. The connection is kept. |

Errors use the [standard error format](/api#errors).
