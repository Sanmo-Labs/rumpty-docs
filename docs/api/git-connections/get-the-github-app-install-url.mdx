<Endpoint method={"GET"} path={"/v1/git-connections/github-app/install-url"} />

Returns a GitHub URL that installs the RumptyCloud GitHub App and connects it to this
workspace. Open the URL in a browser while signed in to GitHub, choose the account or
organization and the repositories to grant, and confirm.

GitHub then sends the browser back to RumptyCloud, which records the connection for this
workspace and redirects to the RumptyCloud console at the `return_to` path. The URL carries
a signed `state` that is valid for **10 minutes**, so request a new one if it expires.

Completing the install needs a browser. When it is done, the connection appears in
[List GitHub App installations](/api/git-connections/list-github-app-installations).

Requires the `secrets manage` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Query parameters

<Param name={"return_to"} type={"string"}>

Console path to return to after installing, for example `/deployments/new`. Must be a
relative path starting with `/`. `github=connected` is added to its query string.
Absolute URLs and invalid values are replaced with the default,
`/deployments/new?github=connected`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `500` | The GitHub App is not configured on the platform, or the install link could not be created. |

Errors use the [standard error format](/api#errors).
