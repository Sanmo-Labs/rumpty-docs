<Endpoint method={"GET"} path={"/v1/git-connections/github-app/detect"} />

Inspects a repository branch's file list and suggests how to build and run it: whether it
is a `static` site or a `service`, the framework, the root directory (for monorepos) and the
recommended build method. Only file names are inspected, not file contents.

How detection works:

- The repository root and common app folders (`apps/web`, `frontend`, `web`, `api`,
  `server`, `backend` and so on) are checked, along with every other folder. The best match
  wins.
- Framework config files are recognised first, for example Next.js, Nuxt, Remix and
  SvelteKit (`service`), and Astro, Gatsby, Angular and Vite (`static`). Then Go, Rust,
  Laravel, PHP, Rails, Ruby, Java, Elixir and Deno projects (`service`). Then generic
  markers: `package.json`, `requirements.txt`, `pyproject.toml`, `index.php` and
  `index.html`.
- A `Dockerfile` in a folder makes `dockerfile` the recommended build method and sets
  `dockerfile_path`. `railpack` is always supported.

When nothing is recognised, `detected` is `false` and `recommended_build_method` is
omitted.

Requires the `secrets read` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

<Param name={"app_type"} type={"string"} enumValues={["static","service"]}>

`static` for sites built to static files, `service` for apps that run a server. Omitted when nothing was detected.

<Param name={"framework"} type={"string"}>

Detected framework or language, for example `Next.js`, `Vite`, `Go`, `Python`, `Static site` or `Dockerfile`. Omitted when nothing was detected.

</Param>

<Param name={"recommended_build_method"} type={"string"} enumValues={["railpack","dockerfile"]}>

Suggested build method. `dockerfile` when a Dockerfile was found, otherwise `railpack`. Omitted when nothing was detected.

</Param>

<Param name={"supported_build_methods"} type={"array of strings"} required enumValues={["railpack","dockerfile"]}>

Build methods that can be used. Always includes `railpack`. `dockerfile` is added when a Dockerfile was found.

</Param>

<Param name={"root_directory"} type={"string"} required>

Folder the app lives in, relative to the repository root. Empty string for the root.

</Param>

<Param name={"dockerfile_path"} type={"string"}>

Path of the detected Dockerfile. Omitted when there is none.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `400` | `repo` is missing or contains spaces. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | No GitHub account is connected, or none matches the repository's owner. |
| `500` | GitHub could not be reached, or the repository or branch is not accessible to the app. |

Errors use the [standard error format](/api#errors).
