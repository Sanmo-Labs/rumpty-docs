<Endpoint method={"POST"} path={"/v1/git-connections/github-app/installations/{uid}/link"} />

Connects a GitHub account you already connected in another workspace to this workspace,
without visiting GitHub. Use a `uid` from
[List reusable GitHub App installations](/api/git-connections/list-reusable-github-app-installations).
Send no request body.

The connection is checked with GitHub first. If the app was uninstalled from that GitHub
account, the request fails with `409` and you need to connect again with
[Get the GitHub App install URL](/api/git-connections/get-the-github-app-install-url).
Linking an account that is already connected here refreshes the existing connection.

Requires the `secrets manage` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The `uid` of a connection you made in another workspace, from [List reusable GitHub App installations](/api/git-connections/list-reusable-github-app-installations).

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The GitHub account is now connected to this workspace. No `data` is returned.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, or your role cannot connect GitHub in it. |
| `404` | No GitHub connection with this `uid` was made by you. |
| `409` | The GitHub App is no longer installed on that GitHub account. |

Errors use the [standard error format](/api#errors).
