<Endpoint method={"GET"} path={"/v1/git-connections/github-app/branches"} />

Returns the branches of a repository the GitHub App can access. The connection used is the
one whose GitHub account matches the repository's owner. Only the first 100 branches that
GitHub returns are included.

Requires the `secrets read` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Query parameters

<Param name={"repo"} type={"string"} required>

Repository in `owner/name` form, as in `full_name` from [List GitHub repositories](/api/git-connections/list-github-repositories). Must not contain spaces.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The repository's branches.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"array of objects"}>

<ParamChildren open label={"item attributes"}>

<Param name={"name"} type={"string"} required>

Branch name.

</Param>

<Param name={"commit_sha"} type={"string"}>

SHA of the branch's latest commit.

</Param>

<Param name={"default"} type={"boolean"} required>

Meant to flag the default branch, but currently always `false`. Use `default_branch` from [List GitHub repositories](/api/git-connections/list-github-repositories) instead.

</Param>

</ParamChildren>

</Param>

## Errors

| Status | Meaning |
|---|---|
| `400` | `repo` is missing or contains spaces. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | No GitHub account is connected, or none matches the repository's owner. |
| `500` | GitHub could not be reached, or the repository is not accessible to the app. |

Errors use the [standard error format](/api#errors).
