<Endpoint method={"GET"} path={"/v1/git-connections/github-app/installations/reusable"} />

Returns GitHub accounts **you** connected in your other workspaces that are not connected to
this workspace yet. Pass a result's `uid` to
[Link a GitHub App installation](/api/git-connections/link-a-github-app-installation) to
connect it here without going through GitHub again.

Only connections you made yourself are listed, because connecting proved you control that
GitHub account. Each GitHub installation appears once, even if it is connected to several
of your workspaces.

Requires the `secrets manage` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
