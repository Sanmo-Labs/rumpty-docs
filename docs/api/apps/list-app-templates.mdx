<Endpoint method={"GET"} path={"/v1/apps/templates"} />

Returns the catalog of enabled one-click app templates, sorted by name. Pass a template's
`slug` as `template` when you [create an app](/api/apps/create-an-app).

`from_monthly_cents` is the starting monthly price: the default web plan, each component's
pinned plan and the included persistent volumes.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
