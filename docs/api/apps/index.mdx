One-click apps install ready-made software, such as WordPress or Uptime Kuma, from a catalog
of templates. An app is a group of managed [deployments](/api/deployments/list-deployments)
called **components**: usually a public `web` component plus private backing services such as
a `database`, each with its own plan and persistent volume. Components run pinned, prebuilt
images instead of building from a Git repository, and their passwords and secrets are
generated for you.

A regular deployment is something you build from your own code and manage directly. An app
owns its components: they are created and deleted together, they carry an `app_uid`, they are
left out of [List deployments](/api/deployments/list-deployments), and they cannot be deleted
or moved to another plan on their own. You can still read and manage a component through the
deployment endpoints, for example to add a custom domain to the web component or read its
metrics.
