<Endpoint method={"DELETE"} path={"/v1/deployments/{uid}/runs/{run_uid}/artifact"} />

Deletes the container image built by a run to free storage. The run stays in the history,
but it can no longer be redeployed. If the run has no image, the run is returned
unchanged.

You cannot delete the image that is currently being served, or the image of the latest run
while it is still in progress.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
