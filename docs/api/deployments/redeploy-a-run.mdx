<Endpoint method={"POST"} path={"/v1/deployments/{uid}/runs/{run_uid}/deploy"} />

Rolls the deployment back (or forward) to the image built by an earlier run, without
rebuilding. A new run is created with the source run's commit details and the current
environment variables and settings.

The source run must still have its build image (see `image_digest`), and it must not be
the version already being served. Images can be removed by `artifact_retention` or by
[Delete a run artifact](/api/deployments/delete-a-run-artifact).

This is asynchronous. It returns `202 Accepted` with an `operation_id` and the new `run`.
See [Get an operation](/api/operations/get-an-operation).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
