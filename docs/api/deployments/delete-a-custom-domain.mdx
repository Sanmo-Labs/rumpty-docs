<Endpoint method={"DELETE"} path={"/v1/deployments/{uid}/custom-domains/{domain_uid}"} />

Removes the custom domain. It disappears from
[List custom domains](/api/deployments/list-custom-domains) immediately, and its route is
torn down by a `delete_custom_domain` operation. If it was the deployment's primary
domain, `public_url` goes back to the platform hostname, and URL-derived environment
variables are rewritten and re-applied.

This is asynchronous. It returns `202 Accepted` with an `operation_id`. See
[Get an operation](/api/operations/get-an-operation).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
