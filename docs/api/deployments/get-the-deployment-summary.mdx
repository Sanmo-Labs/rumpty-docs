<Endpoint method={"GET"} path={"/v1/deployments/summary"} />

Returns deployment counts for the workspace, using the same set of deployments as [List deployments](/api/deployments/list-deployments).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The deployment counts.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"object"}>

<ParamChildren open label={"attributes"}>

<Param name={"total"} type={"integer"} required>

Number of deployments.

</Param>

<Param name={"active"} type={"integer"} required>

Deployments with status `active`.

</Param>

<Param name={"building"} type={"integer"} required>

Deployments whose display status is building, updating, queued or deploying.

</Param>

<Param name={"needs_attention"} type={"integer"} required>

Deployments with status `failed`.

</Param>

</ParamChildren>

</Param>
