<Endpoint method={"GET"} path={"/v1/deployments/{uid}/env-vars"} />

Returns the deployment's environment variables, sorted by key. Values are never returned
here; `masked_value` is always `••••••••`. To read one value, use
[Reveal an environment variable](/api/deployments/reveal-an-environment-variable).

Requires a workspace role that can read secrets (viewers cannot).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The deployment's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
