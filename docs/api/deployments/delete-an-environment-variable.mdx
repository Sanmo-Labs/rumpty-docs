<Endpoint method={"DELETE"} path={"/v1/deployments/{uid}/env-vars/{env_uid}"} />

Deletes the environment variable. If it is part of the running app's environment, the
removal is staged and takes effect on the next deploy, like any other change. Requires a
workspace role that can manage secrets.

The response is `200` even if no variable with this UID exists on the deployment.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The deployment's `uid`.

</Param>

<Param name={"env_uid"} type={"string"} required>

The environment variable's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The variable was deleted.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>
