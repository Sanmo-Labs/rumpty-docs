<Endpoint method={"GET"} path={"/v1/deployments/{uid}/metrics/current"} />

Returns the latest resource sample for the deployment: replicas, CPU, memory, network and
volume usage, summed across replicas. Percentages are relative to the plan's limits.

If no sample has been received yet, `available` is `false`, `unavailable_reason` explains
why, and only the limits are filled in. `stale` is `true` when the latest sample is more
than two minutes old.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
