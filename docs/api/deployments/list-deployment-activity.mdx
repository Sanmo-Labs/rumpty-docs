<Endpoint method={"GET"} path={"/v1/deployments/activity"} />

Returns how many runs were started per day across the whole workspace, with how many
succeeded (`ready`) and failed. Only days with at least one run are included, oldest first.
Days are calendar dates in West Africa Time (UTC+1).

This counts every run in the workspace, including runs of pull request previews and of
one-click app components. For a single deployment, use
[List activity for a deployment](/api/deployments/list-activity-for-a-deployment).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Query parameters

<Param name={"days"} type={"integer"} defaultValue={"365"} constraints={"min 1 · max 366"}>

How many days back to count, up to `366`. Missing, non-numeric, zero, negative or larger values use `365`.

</Param>
