<Endpoint method={"GET"} path={"/v1/deployments/{uid}/runs/{run_uid}/logs"} />

Returns all stored log lines of a run (build and rollout output), oldest first. Old log
lines are cleaned up after a retention period, so logs of old runs may be empty.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The deployment's `uid`.

</Param>

<Param name={"run_uid"} type={"string"} required>

The run's `uid`.

</Param>

</Param>
