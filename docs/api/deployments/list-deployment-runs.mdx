<Endpoint method={"GET"} path={"/v1/deployments/{uid}/runs"} />

Returns the deployment's runs (builds and rollouts), newest first. `security_scan` carries
only the vulnerability counts here; get a single run for the full list.

Without query parameters, every run is returned. Send `page` or `page_size` to paginate;
a top-level `pagination` object is then added next to `data`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The deployment's `uid`.

</Param>

## Query parameters

<Param name={"page"} type={"integer"} constraints={"min 1"}>

Page number, starting at 1. Sending this enables pagination.

</Param>

<Param name={"page_size"} type={"integer"} defaultValue={"10"} constraints={"min 1 · max 100"}>

Runs per page. Defaults to `10`, capped at `100`. Sending this enables pagination.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
