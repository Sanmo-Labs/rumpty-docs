<Endpoint method={"GET"} path={"/v1/deployments/plans"} />

Returns the compute plans available for deployments, cheapest first. Only plans that are
currently available are listed. Use a plan's `slug` as `plan_slug` when you
[create a deployment](/api/deployments/create-a-deployment) or
[change its plan](/api/deployments/change-a-deployment-plan).

Plans with `free_allowance_count` above `0` are Free plans. A Free app always scales to zero
when idle, runs a single instance, and counts toward a per-account allowance (see
[Get the free app quota](/api/deployments/get-the-free-app-quota)).

The list can include plans reserved for one-click app components, such as
`deploy-backing`. Those cannot be chosen when creating a deployment or changing a plan
(`invalid deployment plan`).

This endpoint needs an API key but no workspace.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.
