<Endpoint method={"GET"} path={"/v1/deployments/{uid}/traffic"} />

Returns HTTP traffic served through the deployment's public route over the chosen range:
request and 5xx error counts per time bucket, totals, the error rate and bytes in and
out. Traffic on the platform hostname and on all custom domains is added together.

When traffic data cannot be read (not available in this environment, the app has no public
route, or the metrics backend is temporarily down), the response is still `200` with
`available: false` and a reason in `unavailable_reason`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
