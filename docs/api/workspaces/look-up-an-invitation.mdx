<Endpoint method={"GET"} path={"/v1/workspace-invitations/{token}/lookup"} />

Returns the basic details of an invitation from the token in its email link, so a signed-out
invitee can be sent to sign in or sign up. `account_exists` tells you which.

This endpoint is public and needs no API key or workspace: holding the token is the
credential. `status` is reported as `expired` once the invitation is past its expiry, even if
it was never marked expired. Responses are sent with `Cache-Control: no-store`.

## Authentication

This endpoint is public. No API key is needed.

## Path parameters

<Param name={"token"} type={"string"} required>

The secret token from the invitation email link (`/invitations/<token>`).

</Param>

</Param>

<Param name={"invited_by"} type={"string"}>

Username of the person who sent the invitation. Omitted when unknown.

</Param>

<Param name={"account_exists"} type={"boolean"} required>

Whether a RumptyCloud account already uses the invited email. Use it to choose between sign-in and sign-up.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `404` | The token does not match any invitation (`invitation not found`). |
| `429` | Rate limit exceeded. Wait the number of seconds in the `Retry-After` header before retrying. |

Errors use the [standard error format](/api#errors).
