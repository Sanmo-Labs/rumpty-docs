<Endpoint method={"POST"} path={"/v1/workspaces"} />

Creates a workspace and makes you its owner. This endpoint needs no `X-Workspace-Slug` header.

The slug is generated from the name plus the first 8 characters of the new workspace's `uid`,
so `Staging` becomes something like `staging-019a8f2c`. Use the returned `slug` in
`X-Workspace-Slug` for requests in the new workspace. Workspace names do not have to be
unique.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Errors

| Status | Meaning |
|---|---|
| `400` | Validation failed: `invalid request` (malformed JSON or `name` missing), `workspace name cannot be empty`, or `workspace name must contain alphanumeric characters`. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |

Errors use the [standard error format](/api#errors).
