<Endpoint method={"DELETE"} path={"/v1/workspaces/{workspace_uid}"} />

Permanently deletes a workspace you own, together with its members, pending invitations and
any leftover records. The audit history is kept but no longer linked to the workspace. This
endpoint needs no `X-Workspace-Slug` header.

You can only delete a workspace when:

- you are its owner (other members get `404`),
- it is not your default workspace, and
- it has no VMs, volumes, databases, Kubernetes clusters, storage buckets or deployments left.
  Delete those first.

The response contains the deleted workspace. `role` and `permissions` are not included.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Path parameters

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | The workspace cannot be deleted: `default workspace cannot be deleted` or `workspace still has resources; delete the resources first`. |
| `404` | No workspace with this `uid` is owned by you (`workspace not found`). |

Errors use the [standard error format](/api#errors).
