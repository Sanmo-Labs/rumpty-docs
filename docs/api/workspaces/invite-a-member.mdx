<Endpoint method={"POST"} path={"/v1/workspaces/{workspace_uid}/invitations"} />

Emails an invitation to join the workspace. The email contains a link with a secret token. The
token is never returned by the API. The invitee opens the link, signs in or signs up with the
invited email address, and accepts. See
[Accept an invitation](/api/workspaces/accept-an-invitation).

Invitations expire after 72 hours. Use
[Resend an invitation](/api/workspaces/resend-an-invitation) to send a fresh link.

Requires the owner or admin role. Admins cannot invite someone as `admin`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

## Errors

| Status | Meaning |
|---|---|
| `400` | Validation failed: `email and role are required`, `a valid email address is required`, or `role must be admin, developer, or viewer`. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | Your role cannot manage members, or you are an admin inviting someone as `admin` (`admins cannot assign the admin role`). |
| `409` | Conflict: `you are already a member of this workspace` (you invited yourself), `user is already a member of this workspace`, or `a pending invitation already exists for this email`. |
| `429` | Rate limit exceeded. Wait the number of seconds in the `Retry-After` header before retrying. |

Errors use the [standard error format](/api#errors).
