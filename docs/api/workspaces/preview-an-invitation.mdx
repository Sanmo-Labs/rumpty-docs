<Endpoint method={"GET"} path={"/v1/workspace-invitations/{token}"} />

Returns an invitation addressed to you, with the workspace it is for, so you can review it
before [accepting it](/api/workspaces/accept-an-invitation). Use the token from the
invitation email.

Needs a verified account whose email matches the invited address. No `X-Workspace-Slug`
header is needed, since you may not belong to any workspace yet. If the invitation has
expired, it is marked expired and `409` is returned. Responses are sent with
`Cache-Control: no-store`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Path parameters

<Param name={"token"} type={"string"} required>

The secret token from the invitation email link (`/invitations/<token>`).

</Param>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | Your email is not verified (`action: verify_email`), or the invitation was sent to a different address (`this invitation was sent to a different email address`). |
| `404` | The token does not match any invitation (`invitation not found`). |
| `409` | `invitation is no longer pending` (already accepted, revoked or expired) or `invitation has expired`. |
| `429` | Rate limit exceeded. Wait the number of seconds in the `Retry-After` header before retrying. |

Errors use the [standard error format](/api#errors).
