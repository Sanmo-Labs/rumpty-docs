<Endpoint method={"GET"} path={"/v1/workspaces"} />

Returns every workspace you are an active member of, newest first, with your role and
permissions in each. This endpoint needs no `X-Workspace-Slug` header.

Without query parameters, every workspace is returned in `data`. Send `page` or `page_size` to
paginate. A top-level `pagination` object is then added next to `data`, and `q` filters the
results. `q` is ignored unless `page` or `page_size` is present.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Query parameters

<Param name={"page"} type={"integer"} constraints={"min 1"}>

Page number, starting at 1. Values below 1 (or non-numbers) are treated as `1`. Sending this enables pagination.

</Param>

<Param name={"page_size"} type={"integer"} defaultValue={"10"} constraints={"min 1 · max 100"}>

Items per page. Defaults to `10`. Values above `100` are capped at `100`. Sending this enables pagination.

</Param>

<Param name={"q"} type={"string"}>

Case-insensitive substring search across the workspace's name, slug and description. Only applied when paginating.

</Param>
