<Endpoint method={"GET"} path={"/v1/invoices"} />

Returns your 50 most recent invoices, newest first, each with its line items. Invoices are
created for completed billing cycles.

Requires a verified email address.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.
