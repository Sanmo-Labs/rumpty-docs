<Endpoint method={"GET"} path={"/v1/wallet/cards"} />

Returns the cards you saved for payments, default card first, then newest first. Only display
details are returned. Card numbers are never stored.

Cards are added through the browser checkout in the console.

Requires a verified email address.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.
