<Endpoint method={"GET"} path={"/v1/invoices/{uid}/pdf"} />

Returns the invoice as a PDF tax invoice. Amounts are shown in the invoice's charge
currency. The response is the raw PDF file, not JSON, with a `Content-Disposition` header
naming it `invoice-<number>.pdf`. Errors are still returned as JSON.

Requires a verified email address.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The invoice's `uid`.

</Param>

## Response

<ResponseBlock status={"200"}>

The invoice PDF.

</ResponseBlock>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | Your email address is not verified (`action: verify_email`), or your account is suspended for abuse (`action: account_suspended`). |
| `404` | You have no invoice with this `uid` (`invoice not found`). |

Errors use the [standard error format](/api#errors).
