<Endpoint method={"GET"} path={"/v1/billing/summary"} />

Returns your usage and charges for the current billing cycle, across every workspace you own.
Usage is brought up to date when you call this, so the totals include charges up to now.

- `breakdown` groups this cycle's charges by resource type and metric, with each resource's
  share in `resources`, including resources removed earlier in the cycle.
- `current_resources` lists what is billable right now, grouped by resource type and plan,
  with the hourly and monthly rate of each.
- `free_allowances` shows how much of each free tier you have used, including the AI
  inference token allowance.

Requires a verified email address.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.
