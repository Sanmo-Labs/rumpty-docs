<Endpoint method={"GET"} path={"/v1/audit-logs"} />

Returns audit log entries, newest first. Only actions that change something (creating,
updating, deleting, starting a VM and so on) are recorded. Reads are not logged. Each action
is logged whether it succeeded or failed.

There are two views:

- **Your activity** (default): every entry where you were the actor, across all workspaces.
- **Workspace trail**: send the `workspace_slug` query parameter to get every member's
  entries for that workspace. You need the owner or admin role in the workspace.

This endpoint does **not** read the `X-Workspace-Slug` header. Use the `workspace_slug` query
parameter to select a workspace.

Paging details are in a top-level `meta` object next to `data`. Entry fields use PascalCase
names. Entries identify the acting user and the workspace by UID only (`UserUID`,
`WorkspaceUID`); they do not include account or workspace details.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.

## Query parameters

<Param name={"workspace_slug"} type={"string"}>

Slug of a workspace to return the shared audit trail for. Requires the owner or admin role in that workspace. Omit it to get your own activity.

</Param>

<Param name={"action"} type={"string"}>

Filter by action. A value ending in `.success` or `.failed` matches exactly. Any other
value matches every outcome of that action, so `vm.create` matches `vm.create.success`
and `vm.create.failed`.

</Param>

<Param name={"resource_type"} type={"string"}>

Only return entries for this resource type, e.g. `vm`, `snapshot`, `ssh_key`, `workspace_member`.

</Param>

<Param name={"resource_uid"} type={"string"}>

Only return entries about the resource with this UID.

</Param>

<Param name={"from"} type={"string (date-time)"}>

</Param>

<Param name={"to"} type={"string (date-time)"}>

</Param>

<Param name={"page"} type={"integer"} defaultValue={"1"} constraints={"min 1"}>

</Param>

<Param name={"page_size"} type={"integer"} defaultValue={"50"} constraints={"min 1 · max 200"}>
