<Endpoint method={"POST"} path={"/v1/policies/acceptable-use/accept"} />

Accepts the current version of every policy in the acceptable use policy for your account.
You must do this once before you can [create a VM](/api/virtual-machines/create-a-vm),
a deployment or an app. Those endpoints return `428` until you have.

No request body is needed. The acceptance is recorded with the time, your IP address and your
user agent. Calling it again is safe: it refreshes `accepted_at`.

Returns the updated status, the same shape as
[Get acceptable use policy status](/api/account/get-acceptable-use-policy-status).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`.
