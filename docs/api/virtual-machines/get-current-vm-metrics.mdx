<Endpoint method={"GET"} path={"/v1/vms/{uid}/metrics/current"} />

Returns the latest CPU, memory, disk and network sample reported by the guest agent.

If no sample has arrived yet, `available` is `false`, the metric fields are left out and
`unavailable_reason` explains why. `stale` is `true` when the latest sample is more than two
minutes old.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The VM's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
