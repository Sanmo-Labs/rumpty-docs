<Endpoint method={"GET"} path={"/v1/plans"} />

Returns the compute plans you can create a VM on, cheapest first. Only plans that are
currently available are listed.

This endpoint is public and needs no API key or workspace.

## Authentication

This endpoint is public. No API key is needed.
