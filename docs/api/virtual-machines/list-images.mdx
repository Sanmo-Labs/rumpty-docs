<Endpoint method={"GET"} path={"/v1/images"} />

Returns the enabled operating system images you can create a VM from, grouped by family.
Database engine images are not included.

This endpoint is public and needs no API key or workspace.

## Authentication

This endpoint is public. No API key is needed.
