<Endpoint method={"GET"} path={"/v1/vms/{uid}/firewall-policies"} />

Returns the firewall policies attached to the VM, with their rules and every resource each
policy is attached to. Returns an empty list when no policy is attached. To attach or detach a
policy, use [Attach a firewall policy](/api/firewall-policies/attach-a-firewall-policy).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The VM's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>
