Create and manage virtual machines (VMs) in a workspace: pick a plan, image and zone, control
the VM's power state, resize it, read its metrics, expose ports over HTTPS, attach custom
domains and run one-off commands.

Most write actions are asynchronous. They queue an operation and return `202 Accepted` with an
`operation_id`. Poll [Get an operation](/api/operations/get-an-operation) to follow it.
