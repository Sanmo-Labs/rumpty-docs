<Endpoint method={"GET"} path={"/v1/vms/summary"} />

Returns VM counts for the workspace. VMs that are deleting or deleted are not counted.
`stopped_vms` is every counted VM that is not `running`, so it includes VMs that are
provisioning or failed.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

VM counts for the workspace.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"object"}>

<ParamChildren open label={"attributes"}>

<Param name={"total_vms"} type={"integer"} required>

VMs in the workspace, excluding ones that are deleting or deleted.

</Param>

<Param name={"running_vms"} type={"integer"} required>

VMs whose status is `running`.

</Param>

<Param name={"stopped_vms"} type={"integer"} required>

`total_vms` minus `running_vms`. Includes VMs that are provisioning or failed, not only stopped ones.

</Param>

</ParamChildren>

</Param>
