<Endpoint method={"POST"} path={"/v1/vms/{uid}/domains"} />

Registers a custom domain for the VM's app URL. The domain starts as `pending`. Nothing is
routed until you verify it.

To verify, create two DNS records at your DNS provider, then call
[Verify a custom domain](/api/virtual-machines/verify-a-custom-domain):

- A `CNAME` record for the domain pointing to the VM's `app_hostname`.
- A `TXT` record at `rumpty-challenge.<domain_name>` whose value is the returned
  `verification_txt`.

Root (apex) domains such as `acme.com` are not supported yet. Use a subdomain such as
`www.acme.com`. A domain can only be registered once across RumptyCloud.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Request body

<Param name={"domain_name"} type={"string"} required>

Fully qualified subdomain to attach. Lowercased and trimmed. Must contain only letters, digits, hyphens and dots, and end in a TLD of at least two letters.

</Param>

| `400` | Validation failed: `invalid request`, `domain name is required`, `invalid domain name format`, or the domain is a root domain. |

| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
