<Endpoint method={"GET"} path={"/v1/zones"} />

Returns the zones VMs can run in. There is currently one zone, `olas-closet`, which is also
the default when you create a VM without a `zone_slug`.

This endpoint is public and needs no API key or workspace.

## Authentication

This endpoint is public. No API key is needed.
