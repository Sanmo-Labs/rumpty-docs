<Endpoint method={"DELETE"} path={"/v1/firewall-policies/{uid}/rules/{rule_uid}"} />

Deletes a rule from the policy, including the default SSH and app-port rules. A
`firewall.apply` operation is queued for every resource the policy is attached to, but its
ID is not returned.

Deleting the SSH rule from a policy attached to a VM can block `rumpty ssh` unless another
attached policy still allows port 22.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

<Param name={"rule_uid"} type={"string"} required>
