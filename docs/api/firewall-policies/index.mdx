Firewall policies control which traffic can reach your VMs, databases and deployments. A
policy is a named set of allow rules (protocol, port range and source CIDR). Attach a policy
to a resource to enforce it. Policies belong to the workspace and can be attached to many
resources.

A resource with no policy attached is not filtered. Once one or more policies are attached,
only inbound traffic matching an allow rule of one of them is let through. Rules are
allow-only: there are no deny rules.

Changing rules or attachments queues a `firewall.apply` operation for every affected
resource. Where a response includes an `operation_id`, you can follow it with
[Get an operation](/api/operations/get-an-operation).
