<Endpoint method={"GET"} path={"/v1/databases/versions"} />

Returns the engine versions you can create a database with, one entry per engine and
version. Pass `engine` and `version` from this list to
[Create a database](/api/databases/create-a-database).

Engines are `postgres`, `mysql` and `redis`. The `redis` engine runs Valkey, a
Redis-compatible server.

This endpoint is public and needs no API key or workspace.

## Authentication

This endpoint is public. No API key is needed.
