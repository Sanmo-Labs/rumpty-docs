<Endpoint method={"GET"} path={"/v1/databases/{uid}/credentials"} />

**Returns secrets.** The response contains the database password in plain text and
connection strings with the password embedded. Treat it like the password itself: do
not log it or store it in plain text.

Requires the `secrets read` permission (owner, admin or developer role). Viewers get
`403`. Works in any status, including while the database is still provisioning.

`connection_string` is the public endpoint and is an empty string for a private MySQL or
Redis database. `internal_connection_string` only works from workloads running on
RumptyCloud. `ca_certificate` is the PEM certificate to verify the server's TLS
certificate (for example `sslrootcert` for PostgreSQL or `--cacert` for `redis-cli`).

After a successful [password rotation](/api/databases/rotate-the-database-password), this
returns the new password.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
