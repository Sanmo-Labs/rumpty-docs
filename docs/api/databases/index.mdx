Managed PostgreSQL, MySQL and Redis-compatible (Valkey) databases. Pick a plan and engine
version, read the connection details and credentials, browse data with read-only queries,
take snapshots, resize to another plan and follow metrics.

Creating, resizing, deleting, rotating the password and every snapshot action are
asynchronous. They queue an operation and return its `operation_id`. Poll
[Get an operation](/api/operations/get-an-operation) to follow it.

Databases are owned by the workspace owner's account. Every database endpoint only sees
databases created in the workspace named by `X-Workspace-Slug`.
