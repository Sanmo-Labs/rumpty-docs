<Endpoint method={"POST"} path={"/v1/databases"} />

Queues a new database and returns `202 Accepted` with the `operation_id` of the create
operation. The database starts in `provisioning` and becomes `ready` when the operation
succeeds. Poll [Get an operation](/api/operations/get-an-operation) or
[Get a database](/api/databases/get-a-database) to follow it.

**The response contains the generated password** in `database.password`, and in
`database.connection_string` and `database.internal_connection_string`. You can read it
again later with [Get database credentials](/api/databases/get-database-credentials).

Things to know:

- Pick `engine` and `version` from [List database versions](/api/databases/list-database-versions)
  and a `plan_slug` for the same engine from [List database plans](/api/databases/list-database-plans).
  `engine` is case-insensitive and `postgresql` is accepted as `postgres`.
- The engine's default user is created for you: `postgres` for PostgreSQL, `rumpty` for
  MySQL and `default` for Redis. For PostgreSQL and MySQL the database name is the name's
  slug with `-` replaced by `_` (for example `orders-db` becomes `orders_db`).
- PostgreSQL databases always get a public hostname on port `5432`. MySQL and Redis
  databases only get a public hostname when `public_access` is `true`. They are then
  reached on a dedicated port, returned as `public_port`. Public Redis connections use TLS
  (`rediss://`). Private databases are reachable only through `internal_host` from
  workloads running on RumptyCloud.
- Free plans (`monthly_price_cents` of `0`) are limited to 2 active databases per account,
  across every engine and workspace. Check [Get the free database quota](/api/databases/get-the-free-database-quota).
- Names are not required to be unique, but must contain at least one letter or digit.
- To create a database from a snapshot, send `snapshot_uid`. The engine, version and plan
  are then taken from the snapshot's source database (your `engine`, `version` and
  `plan_slug` are ignored), as are the database name and user. Storage is at least the
  source database's storage. Only snapshots of container-runtime databases can be used.

`X-Idempotency` is optional. If you repeat a create with a key you already used for a
database create, the original operation is returned with `200 OK`, `is_replay: true` and
the `X-Idempotency-Replay` header, and nothing new is queued. The replay is checked before
anything else (billing, validation, quota), so a retry still gets the original result.
The `name` is compared by slug: the same key with a different name returns `409` with
`action: idempotency_key_reused`, as does using the key for another action. A replay does
not include the password.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

Optional unique key for this request, such as a UUID. Leading and trailing spaces are

## Request body

<Param name={"name"} type={"string"} required>

Display name of the database. Leading and trailing spaces are trimmed. Its slug is used for the default database name.

</Param>

<Param name={"engine"} type={"string"} enumValues={["postgres","postgresql","mysql","redis"]}>

Database engine. Case-insensitive; `postgresql` is treated as `postgres`. `redis` runs Valkey. Required unless `snapshot_uid` is set.

</Param>

<Param name={"version"} type={"string"}>

Engine version from [List database versions](/api/databases/list-database-versions). Required unless `snapshot_uid` is set.

</Param>

<Param name={"plan_slug"} type={"string"}>

Slug of an available database plan for the same engine. Case-insensitive. Required unless `snapshot_uid` is set.

</Param>

<Param name={"zone_slug"} type={"string"}>

Optional zone. When set it must match the plan's zone, otherwise the request fails. The database always runs in the plan's zone.

</Param>

<Param name={"public_access"} type={"boolean"} defaultValue={"false"}>

Give a MySQL or Redis database a public hostname and port. PostgreSQL databases always get a public hostname; the value is still stored and returned.

</Param>

<Param name={"snapshot_uid"} type={"string"}>

UID of an `available` database snapshot in this workspace to create the database from. See the notes above.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `400` | Validation failed. Possible messages: `invalid request` (malformed JSON or missing `name`), `name is required`, `name, engine, version, and plan_slug are required`, `that database engine isn't available yet`, `invalid database plan`, `selected plan is not available for that database engine`, `selected database plan is not available in that zone`, `invalid database version`, `that database version isn't available yet`, `database name must contain alphanumeric characters`, `invalid snapshot`, `snapshot source plan is unavailable`, or `create-from-snapshot is only supported for container-runtime database snapshots`. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `402` | The account is past due, so new paid resources cannot be created. |
| `403` | You cannot create resources in this workspace, or the account already has the maximum number of free databases. |
| `409` | The snapshot is not `available` (`snapshot is not ready to restore`), or the `X-Idempotency` key was already used for a different operation (`action: idempotency_key_reused`). |

Errors use the [standard error format](/api#errors).
