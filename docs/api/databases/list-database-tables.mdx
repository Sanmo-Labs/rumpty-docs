<Endpoint method={"GET"} path={"/v1/databases/{uid}/data/tables"} />

Lists the tables and views in a PostgreSQL or MySQL database, for use with
[Browse table rows](/api/databases/browse-table-rows). Redis databases have no tables;
use [List keys](/api/databases/list-keys) instead.

- PostgreSQL: tables, partitioned tables, views, materialized views and foreign tables
  in every schema except the system schemas, limited to those the database user can
  `SELECT`. Partitions are left out. Tables in `public` come first.
- MySQL: tables and views in every schema except `mysql`, `information_schema`,
  `performance_schema` and `sys`. Tables in the database's own schema come first.
- At most 2000 entries are returned.

The database must be `ready`. Data browser calls share a small platform-wide pool of
connections; when it is full you get `409` and should retry shortly. Requires the
`secrets read` permission (owner, admin or developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Errors

| Status | Meaning |
|---|---|
| `400` | The request failed. Possible messages: `this database has no tables, browse its keys instead` (Redis), `the data viewer doesn't support this database engine`, `the database rejected the connection: <reason>`, or an error from the database. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | The resource does not exist or you cannot access it. |
| `409` | The data browser cannot run right now. Possible messages: `the database must be ready to browse its data`, `the data viewer is busy, try again in a moment`, and `couldn't reach the database, check that it's running and try again`. |

Errors use the [standard error format](/api#errors).
