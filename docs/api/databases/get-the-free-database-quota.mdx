<Endpoint method={"GET"} path={"/v1/databases/free-quota"} />

Returns how many free-plan databases the account can still create. The limit is per
account (the workspace owner's account for workspace requests) and spans every engine
and workspace. Databases that are `failed` or deleted do not count.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The free database quota.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"object"}>

<ParamChildren open label={"attributes"}>

<Param name={"limit"} type={"integer"} required>

Maximum number of active free-plan databases per account.

</Param>

<Param name={"used"} type={"integer"} required>

Free-plan databases the account has now, excluding failed and deleted ones.

</Param>

<Param name={"remaining"} type={"integer"} required>

How many more free-plan databases can be created. Never below `0`.

</Param>

</ParamChildren>
