<Endpoint method={"GET"} path={"/v1/database-snapshots"} />

Returns every database snapshot in the workspace, newest first, including snapshots whose
database has been deleted (`detached: true`).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The workspace's database snapshots.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"array of objects"}>

<ParamChildren open label={"item attributes"}>

<Param name={"uid"} type={"string"} required>

Snapshot UID.

</Param>

<Param name={"database_uid"} type={"string"} required>

UID of the database the snapshot was taken from. Still set after that database is deleted.

</Param>

<Param name={"source_database_name"} type={"string"} required>

Name of the source database.

</Param>

<Param name={"source_engine"} type={"string"} enumValues={["postgres","mysql","redis"]}>

Engine of the source database. Omitted when unknown.

</Param>

<Param name={"source_version"} type={"string"}>

Engine version of the source database. Omitted when unknown.

</Param>

<Param name={"detached"} type={"boolean"} required>

`true` when the source database has been deleted. Detached snapshots can still be used to create a database, and can be deleted with [Delete a database snapshot](/api/databases/delete-a-database-snapshot).

</Param>

<Param name={"name"} type={"string"} required>

Snapshot name.

</Param>

<Param name={"slug"} type={"string"} required>

URL-safe version of the name.

</Param>

<Param name={"status"} type={"string"} required enumValues={["creating","available","restoring","deleting","failed"]}>

Snapshot state. Only `available` snapshots can be restored or used to create a database.

</Param>

<Param name={"consumed_bytes"} type={"integer"} required>

Storage used by the snapshot, in bytes. `0` until reported.

</Param>

<Param name={"created_at"} type={"string (date-time)"} required>

When the snapshot was requested.

</Param>

<Param name={"updated_at"} type={"string (date-time)"} required>

When the snapshot last changed.

</Param>

</ParamChildren>

</Param>
