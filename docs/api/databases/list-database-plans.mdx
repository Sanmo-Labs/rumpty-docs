<Endpoint method={"GET"} path={"/v1/databases/plans"} />

Returns the database plans that are currently available, grouped by zone and sorted
cheapest first. Plans are per engine: use a plan whose `engine` matches the engine you
create. A plan with `monthly_price_cents` of `0` is a free plan and counts toward the
[free database quota](/api/databases/get-the-free-database-quota).

This endpoint is public and needs no API key or workspace.

## Authentication

This endpoint is public. No API key is needed.
