<Endpoint method={"GET"} path={"/v1/databases/{uid}/data/rows"} />

Returns one page of rows from a PostgreSQL or MySQL table or view, as
`SELECT * FROM <schema>.<table> LIMIT <limit> OFFSET <offset>` in a read-only
transaction. Rows have no defined order.

`truncated` is `true` when more rows exist after this page (or when the response hit the
4 MiB size cap). The response shape and limits are the same as for
[Run a read-only query](/api/databases/run-a-read-only-query).

The database must be `ready`. Requires the `secrets read` permission (owner, admin or
developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Query parameters

<Param name={"schema"} type={"string"} required>

Schema of the table, as returned by [List database tables](/api/databases/list-database-tables). For MySQL this is the database (schema) name.

</Param>

<Param name={"table"} type={"string"} required>

Name of the table or view. Quoted for you, so pass it exactly as listed.

</Param>

<Param name={"limit"} type={"integer"} defaultValue={"50"} constraints={"min 1 · max 200"}>

Rows per page. Defaults to `50`. Values above `200` are capped at `200`. Zero, negative or non-numeric values use the default.

</Param>

<Param name={"offset"} type={"integer"} defaultValue={"0"} constraints={"min 0"}>

Rows to skip. Defaults to `0`. Negative or non-numeric values are treated as `0`.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `400` | Validation or query failed. Possible messages: `schema and table are required`, `invalid table name`, `this database has no tables, browse its keys instead`, or the database's own error, such as a missing table. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | The resource does not exist or you cannot access it. |
| `409` | The data browser cannot run right now. Possible messages: `the database must be ready to browse its data`, `the data viewer is busy, try again in a moment`, and `couldn't reach the database, check that it's running and try again`. |
