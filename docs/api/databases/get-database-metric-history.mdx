<Endpoint method={"GET"} path={"/v1/databases/{uid}/metrics/history"} />

Returns a time series of the database's metrics over a time range. The response uses the
same shape as VM metrics, so the database's UID is returned in `vm_uid`. The step between
points depends on the range:

| `range` | `step_seconds` |
| ------- | -------------- |
| `15m`   | 15             |
| `1h`    | 60             |
| `6h`    | 300            |
| `24h`   | 900            |
| `7d`    | 3600           |
| `30d`   | 21600          |

If no samples exist in the range, `available` is `false` and `points` is empty.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

## Query parameters

<Param name={"range"} type={"string"} defaultValue={"1h"} enumValues={["15m","1h","6h","24h","7d","30d"]}>

Time window to return, ending now. Case-insensitive. Other values return `400` (`invalid metrics range`).

</Param>
