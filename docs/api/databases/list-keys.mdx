<Endpoint method={"GET"} path={"/v1/databases/{uid}/data/keys"} />

Scans the keys of a Redis (Valkey) database with `SCAN` and returns their type and TTL.
Only available for Redis databases; other engines return `400`.

One call runs up to 20 `SCAN` rounds of 500 until at least 100 keys are found or the scan
completes, so a page can hold more or fewer than 100 keys. Keys in a page are sorted by
name. Pass the returned `cursor` back to continue; `"0"` means the whole keyspace has been
covered. As with any `SCAN`, a key may appear on more than one page.

Key names that are not valid UTF-8 are shown escaped in `key` and given exactly in
`raw_b64`. Use `raw_b64` with `key_b64` on [Get a key](/api/databases/get-a-key).

The database must be `ready`. Requires the `secrets read` permission (owner, admin or
developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
