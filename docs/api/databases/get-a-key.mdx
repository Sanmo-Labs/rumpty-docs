<Endpoint method={"GET"} path={"/v1/databases/{uid}/data/key"} />

Returns one key of a Redis (Valkey) database with its type, TTL, size and value. Only
available for Redis databases.

- `string`: `value` holds the first 64 KiB; `truncated` is `true` when the value is
  longer. `length` is the size in bytes.
- `hash`, `set`, `list`, `zset`, `stream`: `items` holds one page of about 200 entries
  and `length` is the element count. When there is more, pass `next` back as the `next`
  query parameter. `next` is an empty string on the last page.
  Columns are `field`, `value` (hash), `member` (set), `index`, `value` (list),
  `member`, `score` (zset) and `id`, `fields` (stream, with fields as a JSON object).
- Values that are not valid UTF-8 are shown with `\x` escapes. Each cell is cut at 8 KiB.

The database must be `ready`. Requires the `secrets read` permission (owner, admin or
developer role).

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Errors

| Status | Meaning |
|---|---|
| `400` | The request failed. Possible messages: `key is required`, `invalid key_b64`, `invalid page`, `key browsing is only available for Valkey databases`, `db must be between 0 and 15`, or an error from the server. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | The database does not exist, or the key does not exist (`key not found, it may have expired`). |
| `409` | The data browser cannot run right now. Possible messages: `the database must be ready to browse its data`, `the data viewer is busy, try again in a moment`, and `couldn't reach the database, check that it's running and try again`. |
