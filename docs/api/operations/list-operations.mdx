<Endpoint method={"GET"} path={"/v1/operations"} />

Returns all operations in the workspace, newest first. This covers every resource type, not
only VMs, and is not paginated.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

The workspace's operations.

Human-readable status message.

<ParamChildren open label={"item attributes"}>

<Param name={"uid"} type={"string"} required>

Unique identifier of the operation.

</Param>

<Param name={"resource_type"} type={"string"} required>

Kind of resource the operation acts on, for example `vm`, `vm_app`, `vm_snapshot`, `k8s_cluster`, `volume`, `database` or `deployment`.

</Param>

<Param name={"resource_uid"} type={"string"} required>

UID of the resource. For a new VM or snapshot, this is the UID of the resource being created.

</Param>

<Param name={"resource_name"} type={"string"} required>

Name of the resource when the operation was queued.

</Param>

<Param name={"action"} type={"string"} required>

What the operation does. For VMs: `create`, `start`, `stop`, `reboot`, `resize`,
`delete`, `set_app_port`, `expose` and `unexpose` (custom domains and apps). For
snapshots: `create`, `restore` and `delete`. Other resources (`k8s_cluster`, `volume`,
`database`, `deployment`, buckets) use `create` and `delete` plus their own actions, for
example `attach_volume`, `detach_volume`, `resize` or `firewall.apply`.

</Param>

<Param name={"status"} type={"string"} required enumValues={["queued","running","succeeded","failed"]}>

Progress of the operation. `succeeded` and `failed` are final.

</Param>

<Param name={"started_at"} type={"string (date-time)"}>

When work began. Omitted while queued.

</Param>

<Param name={"finished_at"} type={"string (date-time)"}>

When the operation finished. Omitted until it does.

</Param>

<Param name={"created_at"} type={"string (date-time)"} required>

When the operation was queued.

</Param>

<Param name={"events_url"} type={"string"} required>

Path of the server-sent events stream with the operation's progress.

</Param>
