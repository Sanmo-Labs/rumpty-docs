<Endpoint method={"GET"} path={"/v1/ssh-keys"} />

Returns the SSH keys you can use in this workspace, newest first: every key you added (in any
workspace) plus every key other members added to this workspace. Deleted keys are not listed.

Any workspace role can call this.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The SSH keys usable in this workspace.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"array of objects"}>

<ParamChildren open label={"item attributes"}>

<Param name={"uid"} type={"string"} required>

Unique identifier of the key. Use it in `ssh_key_uids` when creating a VM.

</Param>

<Param name={"name"} type={"string"} required>

Label given to the key.

</Param>

<Param name={"fingerprint"} type={"string"} required>

SHA-256 fingerprint of the public key, in the same format as `ssh-keygen -l`.

</Param>

<Param name={"created_at"} type={"string (date-time)"} required>

When the key was added.

</Param>

</ParamChildren>

</Param>
