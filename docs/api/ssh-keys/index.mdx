SSH public keys you can install on VMs. Pass their `uid`s as `ssh_key_uids` when you
[create a VM](/api/virtual-machines/create-a-vm).

A key belongs both to you and to the workspace you add it in. In a workspace you can use
your own keys (including ones you added in other workspaces) and every key other members added
to that workspace. Only the public key is stored. It is never returned by the API, only its
fingerprint.
