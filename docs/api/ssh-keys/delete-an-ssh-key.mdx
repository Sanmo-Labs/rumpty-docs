<Endpoint method={"DELETE"} path={"/v1/ssh-keys/{uid}"} />

Deletes an SSH key.

- Your own keys can be deleted from any workspace you have the developer role or higher in,
  including keys you added in another workspace.
- A key another member added can only be deleted by an owner or admin of the workspace it
  was added in, and only through that workspace. Otherwise the call returns `403`
  (`you can only delete your own ssh keys`).

Deleting a key only removes it from RumptyCloud, so it can no longer be chosen for new VMs.
This endpoint does not change VMs that already have the key installed.

Requires the owner, admin or developer role. Viewers get `403`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

## Errors

| Status | Meaning |
|---|---|
| `400` | The request was malformed or failed validation. |
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | Your role cannot delete keys, or the key belongs to another member and you are not an owner or admin of this workspace. |
| `404` | No key with this `uid` is usable in this workspace (`ssh key not found`): it is neither yours nor added to this workspace. |

Errors use the [standard error format](/api#errors).
