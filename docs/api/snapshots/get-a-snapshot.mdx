<Endpoint method={"GET"} path={"/v1/snapshots/{snapshot_uid}"} />

Returns one snapshot in the workspace, whether or not its source VM still exists.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"snapshot_uid"} type={"string"} required>

The snapshot's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

The snapshot.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"object"}>

<ParamChildren open label={"attributes"}>

<Param name={"uid"} type={"string"} required>

Unique identifier of the snapshot.

</Param>

<Param name={"vm_uid"} type={"string"} required>

UID of the VM the snapshot was taken from. Kept after that VM is deleted.

</Param>

<Param name={"source_vm_name"} type={"string"} required>

Name of the source VM.

</Param>

<Param name={"detached"} type={"boolean"} required>

`true` when the source VM has been deleted. The snapshot can still be used to create a new VM.

</Param>

<Param name={"name"} type={"string"} required>

Name of the snapshot.

</Param>

<Param name={"slug"} type={"string"} required>

URL-safe form of the name.

</Param>

<Param name={"status"} type={"string"} required enumValues={["creating","available","restoring","deleting","failed"]}>

Lifecycle state. Only `available` snapshots can be restored or used to create a VM.

</Param>

<Param name={"consumed_bytes"} type={"integer"} required>

Storage the snapshot actually uses, in bytes. Billing is based on this. `0` until the snapshot is ready.

</Param>

<Param name={"created_at"} type={"string (date-time)"} required>

When the snapshot was requested.

</Param>

<Param name={"updated_at"} type={"string (date-time)"} required>

When the snapshot last changed.

</Param>

</ParamChildren>

</Param>
