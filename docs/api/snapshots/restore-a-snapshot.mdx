<Endpoint method={"POST"} path={"/v1/vms/{uid}/snapshots/{snapshot_uid}/restore"} />

Restores the VM from one of its own snapshots. The snapshot must be `available`. While
the restore runs, the snapshot shows `restoring` and the VM shows `provisioning`.

To start a new VM from a snapshot instead, pass `snapshot_uid` to
[Create a VM](/api/virtual-machines/create-a-vm).

This is asynchronous. It returns `202 Accepted` with an `operation_id`. See
[Get an operation](/api/operations/get-an-operation). Send an `X-Idempotency` key to make
retries safe: a retry with the same key for the same snapshot returns the original
operation with `200`, even after the restore has finished.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

<Param name={"X-Idempotency"} type={"string"}>

Optional unique key for this request, such as a UUID. Leading and trailing spaces are
ignored. If you send a key you already used for the same snapshot action, the original
operation is returned with `200 OK` and `X-Idempotency-Replay: true`, and nothing new is
queued. Reusing a key for a different action or snapshot returns `409` with
`action: idempotency_key_reused`. Keys are shared across the workspace. Without a key,
every request is treated as new.

</Param>

## Errors

| Status | Meaning |
|---|---|
| `401` | The API key is missing, invalid, expired or revoked. |
| `403` | You cannot access the workspace, your role does not allow this action, or the account is suspended. |
| `404` | The VM or snapshot does not exist, or the snapshot was not taken from this VM. |
| `409` | The snapshot is not `available` (`snapshot is not in available state for restore`), or the `X-Idempotency` key was used for a different operation (`action: idempotency_key_reused`). |
