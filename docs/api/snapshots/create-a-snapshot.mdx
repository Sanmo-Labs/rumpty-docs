<Endpoint method={"POST"} path={"/v1/vms/{uid}/snapshots"} />

Queues a snapshot of the VM's disk. The snapshot starts as `creating` and becomes
`available` when it is ready. `consumed_bytes` is filled in then.

This is asynchronous. It returns `202 Accepted` with an `operation_id`. See
[Get an operation](/api/operations/get-an-operation). The new snapshot's UID is the
operation's `resource_uid`. In the response, `name` is the VM's name, not the snapshot's.

Send an `X-Idempotency` key to make retries safe: a retry with the same key returns the
original operation with `200` and nothing new is queued. The key is tied to the VM and
the snapshot `name`: reusing it for another VM or name returns `409` with
`action: idempotency_key_reused`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

The VM's `uid`.

</Param>

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

<Param name={"X-Idempotency"} type={"string"}>

Optional unique key for this request, such as a UUID. Leading and trailing spaces are
ignored. If you send a key you already used for the same snapshot action, the original
operation is returned with `200 OK` and `X-Idempotency-Replay: true`, and nothing new is
queued. Reusing a key for a different action or snapshot returns `409` with
`action: idempotency_key_reused`. Keys are shared across the workspace. Without a key,
every request is treated as new.

</Param>

## Request body

<Param name={"name"} type={"string"} required constraints={"min length 1 · max length 100"}>

Name of the snapshot. Its slug is derived from it.

</Param>

<Param name={"shutdown_before_snapshot"} type={"boolean"} defaultValue={"false"}>

Shut the VM down before taking the snapshot, for a consistent copy of a busy disk.

</Param>
