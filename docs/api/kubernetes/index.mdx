Managed Kubernetes clusters built on [k3s](https://k3s.io). A cluster is one control-plane node
and one to three worker nodes, each running on its own compute plan. When the cluster is ready
you get a public API `endpoint` and a `kubeconfig` to use with `kubectl`.

Creating and deleting clusters is asynchronous. Both return `202 Accepted` with an
`operation_id`. Poll [Get an operation](/api/operations/get-an-operation) or
[Get a cluster](/api/kubernetes/get-a-cluster) to follow progress. Send `X-Idempotency` to
make retries safe: a repeated request returns the original operation with `200 OK`.

If the account is suspended for non-payment, running clusters are powered off (`stopped`)
and restarted automatically once the account is active again.
