Block storage volumes you can attach to a VM for extra disk space. A volume lives on its own,
so its data survives detaching it or deleting the VM it was attached to. A volume can be
attached to one VM at a time, and the VM must be in the same zone.

Creating, attaching, detaching and deleting volumes are asynchronous. They return
`202 Accepted` with an `operation_id`. Poll [Get an operation](/api/operations/get-an-operation)
or [Get a volume](/api/volumes/get-a-volume) to follow progress. Send `X-Idempotency` to
make retries safe: a repeated request returns the original operation with `200 OK`.
