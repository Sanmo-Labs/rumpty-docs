<Endpoint method={"GET"} path={"/v1/volumes/summary"} />

Returns totals across the workspace's volumes. Volumes that are being deleted are not
counted.

Used space comes from the last filesystem usage reported by each VM's guest agent, so
volumes that have never been mounted count as empty.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Headers

<Param name={"X-Workspace-Slug"} type={"string"} required>

Slug of the workspace the request acts on. You can also pass it as the `workspace_slug` query parameter.

</Param>

## Response

<ResponseBlock status={"200"}>

Storage totals for the workspace's volumes.

</ResponseBlock>

<Param name={"success"} type={"boolean"} required>

`true` when the request succeeded.

</Param>

<Param name={"message"} type={"string"} required>

Human-readable status message.

</Param>

<Param name={"data"} type={"object"}>

<ParamChildren open label={"attributes"}>

<Param name={"total_volumes"} type={"integer"} required>

Number of volumes, excluding those being deleted.

</Param>

<Param name={"total_storage_bytes"} type={"integer"} required>

Combined provisioned size of those volumes, in bytes (`size_gib` × 1024³).

</Param>

<Param name={"used_storage_bytes"} type={"integer"} required>

Combined used bytes from each volume's last usage report.

</Param>

<Param name={"available_storage_bytes"} type={"integer"} required>

`total_storage_bytes` minus `used_storage_bytes`, or `0` if used exceeds total.

</Param>

<Param name={"total_used_percent"} type={"number"} required>

`used_storage_bytes` as a percentage of `total_storage_bytes`. `0` when there are no volumes.

</Param>

</ParamChildren>

</Param>
