# List Your Workspaces

`rumpty workspaces` lists the Rumpty workspaces your signed-in account can access. Use a workspace's slug with the `--ws` flag (or `RUMPTY_WORKSPACE`) on any command that needs one.

## Quick start

```bash
rumpty workspaces
```

## Requirements

- A signed-in session (`rumpty login`) or the `RUMPTY_API_KEY` environment variable. See [Login & Logout](./login).
